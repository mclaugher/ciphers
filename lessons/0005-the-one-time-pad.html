The One-Time Pad & Perfect Secrecy

Every cipher so far has fallen. This one never does — it is the only cipher proven unbreakable, by mathematics, forever. The catch is what it costs you.

Where we left off. Vigenère failed because its key repeated, and repetition is a pattern an attacker can find (Lesson 04). At the end we asked the dangerous question: what if the key never repeated — if it were truly random and as long as the message itself? Let's build exactly that.

1 · A key with no pattern to find

The one-time pad is Vigenère pushed to its limit. Instead of a short keyword, the key is a stream of completely random letters, as long as the message, used once and then destroyed.1 Each letter still rides its own shift (C = (P + K) mod 26) — but now there is no repeat to exploit, no frequencies to flatten back out, no period for Kasiski to find. The patterns aren't hidden; they don't exist.

Encrypt with a random pad

A fresh random key for every letter. Generate a new pad and the same message becomes something completely different — and only the matching pad can undo it.

2 · Why it cannot be broken

Here is the most beautiful idea in classical cryptography. Take a short intercept — say the six letters below. An attacker tries to break it. But with a random pad, every six-letter message is a possible answer: for any message you can imagine, there exists a key that turns this exact ciphertext into it.

Shannon's perfect secrecy (1949) Because every plaintext is possible and equally likely, the ciphertext reveals nothing about the message — not even to an enemy with infinite time and computers. Claude Shannon proved this in 1949: the one-time pad has perfect secrecy, and any perfectly secret cipher needs a key at least as long as the message.2

3 · So why don't we all use it?

If it's unbreakable, why was the rest of cryptography ever invented? Because perfection comes with four unforgiving rules — break any one and the magic dies:1

  • The key must be truly random — not a phrase, not a pattern.
  • The key must be as long as the message.
  • The key must be used only once.
  • The key must be shared in secret, in advance.

Reuse a pad even once and you have a two-time pad: subtract the two ciphertexts and the key cancels out (C₁ − C₂ = P₁ − P₂), leaking the messages. This exact mistake let US codebreakers read Soviet cables for years in the VENONA project.3

The problem that creates modern cryptography To send one secret message you must already have secretly shared a key just as big. You haven't removed the problem of sharing a secret — you've made it the same size as all your traffic. That single, practical flaw — the key-distribution problem — is what the modern era was built to solve.3
