Breaking the Vigenère Cipher

You found the key length last time. Now you finish the kill — and watch the "indecipherable" cipher dissolve into the two ciphers you already beat.

Where we left off. In Lesson 03 you used Kasiski's trick — repeated chunks, gap distances, their GCD — to learn that an intercept's key was 5 letters long. That single number is the crack. Here's why.

1 · One long cipher becomes many short ones

If the key has length 5, then letters 1, 6, 11, 16, … were all enciphered with the same key letter. So were letters 2, 7, 12, …, and so on. Deal the ciphertext into 5 columns — like dealing cards — and each column is a plain old Caesar cipher with a single fixed shift.1

And you already know how to break a Caesar cipher by counting letters (Lesson 02): the most common letter in each column is almost certainly E in disguise, so its shift hands you that column's key letter. Five columns → five key letters → the keyword.

Key idea Breaking Vigenère is not one new trick — it is Kasiski (find the key length) followed by frequency analysis run once per column. A polyalphabetic cipher is only as strong as the monoalphabetic pieces it breaks into once its period is known.

3 · So how strong is Vigenère, really?

It was a genuine leap — for 300 years it beat the best codebreakers in Europe. But its strength rested on a repeating key, and repetition is a pattern, and patterns leak. The longer the keyword, the more text an attacker needs and the harder the break — but as long as the key repeats, the door is never fully shut.2

The question that opens the modern era What if the key never repeated — if it were as long as the message itself, and perfectly random? Then there are no repeats to find and every column is one letter long. That cipher turns out to be unbreakable, provably so. It's called the one-time pad, and it's the next lesson.
