The Vigenère Cipher

In Lesson 02 you broke a cipher by counting letters. Now meet the cipher built to erase the very thing you counted — the one Europe called le chiffre indéchiffrable, the indecipherable cipher, for three hundred years.

Where we left off. Frequency analysis crushed substitution because each letter wore one disguise: E always became the same letter, so its 12.7% spike showed straight through. The fix almost suggests itself — what if E wore a different disguise each time it appeared?

1 · One keyword, many Caesars

The Vigenère cipher is a polyalphabetic substitution: instead of one shifted alphabet, it uses 26 of them — the rows of the Vigenère tableau — and a keyword decides which row enciphers each letter.1 Write the keyword over and over above your message; each letter is then just a Caesar shift by its key letter (C = (P + K) mod 26).1

So Vigenère is nothing more exotic than Lesson 01's Caesar cipher, with the shift changing every letter. The keyword is the key.

2 · Why it hid the fingerprint

Here is the magic. Because the shift changes with every key letter, a single plaintext letter scatters across many ciphertext letters. The towering E spike gets smeared across the whole alphabet — and the language fingerprint that doomed substitution simply vanishes.

Watch the fingerprint flatten

The same English passage, counted three ways. Substitution just relabels the spikes; Vigenère levels them.

Key idea A monoalphabetic cipher preserves the shape of the language; a polyalphabetic cipher flattens it. That is why frequency analysis — unstoppable against substitution — hits a wall here. For 300 years, that wall held.1

3 · The crack that finally worked

The break came from a quiet observation, made by Charles Babbage around 1854 (he never published) and later by Friedrich Kasiski in 1863.2 It is this: a repeating key must leave a repeating trace. When a common word like THE happens to line up with the same slice of the keyword twice, it encrypts to the same ciphertext both times. The distance between those repeats must be a multiple of the key length.

So measure the gaps between repeated chunks, take their greatest common divisor, and you have recovered the key length — without knowing the key.

Find the key length (Kasiski's method)

A Vigenère intercept. The repeated block HIMFRDYD is highlighted — count the gap, fold in the other repeats, and find the key length.

Repeat distances found: 60, 45, 20. Their greatest common divisor is the key length.

The payoff — and the next lesson Once you know the key length is n, the spell breaks. Every n-th letter was enciphered with the same key letter — so the message is really n interleaved Caesar ciphers. Split them into columns and you crack each one with the frequency analysis from Lesson 02. The "indecipherable" cipher collapses into the two ciphers you already beat.
