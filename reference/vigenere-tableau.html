The Vigenère Tableau

The tabula recta: 26 Caesar alphabets stacked in a square. A keyword picks which row enciphers each letter — so the same letter can encrypt many different ways.

To encrypt: find the column of your plaintext letter and the row of the current key letter; the cell where they cross is the ciphertext. To decrypt: go to the key letter's row, scan along it for the ciphertext letter, and read the column header.

The arithmetic (with A = 0 … Z = 25)
Encrypt: C = (P + K) mod 26
Decrypt: P = (C − K) mod 26
…where K is the key letter for that position. The keyword repeats over the message: LEMONLEMONLEMON…

Worked example — key LEMON.

plain A T T A C K A T D A W N key L E M O N L E M O N L E cipher L X F O P V E F R N H R

Each letter rides its own Caesar shift: A+L, T+E, T+M, … The repeating key is both the cipher's strength and — because it repeats — its eventual weakness.

A little history

The stacked-alphabet square is Johannes Trithemius's tabula recta (1508). Adding a repeating keyword to it was Giovan Battista Bellaso's idea (1553); the method was later misattributed to Blaise de Vigenère, and the name stuck. For three centuries it was called le chiffre indéchiffrable — "the indecipherable cipher" — until Charles Babbage (c. 1854, unpublished) and Friedrich Kasiski (1863) broke it.1,2
